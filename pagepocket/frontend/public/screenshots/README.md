# Marketing screenshots

Real product captures generated by `scripts/marketing-captures.mjs`
(openspec `professional-marketing-site` task 1.9, design D3/D4 — proof, not
mockups). Regenerate with:

```sh
cd pagepocket/frontend
PP_DEMO_EMAIL=... PP_DEMO_PASSWORD=... node scripts/marketing-captures.mjs all   # seed + capture
PP_DEMO_EMAIL=... PP_DEMO_PASSWORD=... node scripts/marketing-captures.mjs capture # screenshots only
```

All app shots are full-viewport 1440×900 @2x (light **and** dark) against the
production app, browser chrome cropped out. Serve via `next/image` with
explicit sizes.
