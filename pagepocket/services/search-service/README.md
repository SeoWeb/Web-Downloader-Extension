# Search Service

Provides full-text search over archived pages using MySQL's FULLTEXT index with the ngram parser. Runs as a gRPC server on **port 50054**.

## gRPC Methods

### IndexPage

Adds or updates a page in the search index. Upserts by `page_id`.

| Field       | Type   | Description                                              |
| ----------- | ------ | -------------------------------------------------------- |
| `page_id`   | string | Unique page identifier                                   |
| `user_id`   | string | Page owner                                               |
| `url`       | string | Original page URL                                        |
| `title`     | string | Page title                                               |
| `body_text` | string | Plain text content (truncated to 16 MB MEDIUMTEXT limit) |
| `tags`      | string | Optional tags                                            |

Returns `StatusResponse`.

### RemovePage

Removes a page from the search index.

| Field     | Type   | Description               |
| --------- | ------ | ------------------------- |
| `page_id` | string | Page to remove            |
| `user_id` | string | Must match the page owner |

Returns `StatusResponse`.

### Search

Performs a full-text search with pagination and optional collection filtering.

| Field           | Type   | Description                                           |
| --------------- | ------ | ----------------------------------------------------- |
| `user_id`       | string | Restricts results to this user's pages                |
| `query`         | string | Natural language search query (required, non-empty)   |
| `page`          | int32  | Page number (1-based)                                 |
| `page_size`     | int32  | Results per page (max 100, default 20)                |
| `collection_id` | string | Optional filter to pages within a specific collection |

Returns `SearchResponse` with `results` (each containing `page_id`, `url`, `title`, `snippet`, `score`, `archived_at`) and `total` count.

Errors: `INVALID_ARGUMENT` (empty query).

## Search Engine

Uses MySQL's `MATCH ... AGAINST ... IN NATURAL LANGUAGE MODE` against a FULLTEXT index on the `title` and `body_text` columns. The ngram parser enables substring matching for multilingual content.

Snippets are generated by extracting ~240 characters around the first query match in the body text, with `...` ellipsis markers when truncated.

Collection filtering works by joining against the `page_collections` table in the `library_db` database.

## Configuration

| Variable       | Required | Default | Description                        |
| -------------- | -------- | ------- | ---------------------------------- |
| `DB_URL`       | Yes      | —       | SQLAlchemy MySQL connection string |
| `MTLS_ENABLED` | No       | `false` | Enable mutual TLS                  |

## Dependencies

**Python packages:** `grpcio`, `grpcio-tools`, `protobuf`, `sqlalchemy`, `pymysql`

**Shared utilities:** `shared/db.py`, `shared/grpc_mtls.py`, `shared/proto_generated/`.

## Local Development

```bash
cd pagepocket/services/search-service
pip install -r requirements.txt

export DB_URL=mysql+pymysql://user:pass@localhost:3306/pagepocket

python main.py
# Server starts on port 50054
```

## Service Communication

- **Called by:** API gateway (search endpoint), archive service (fire-and-forget `IndexPage`/`RemovePage`)
- **Calls:** None. The search service reads from its own `page_index` table and optionally queries `library_db.page_collections` for collection filtering.

## Database Table

- **`page_index`** — `id` (PK), `page_id` (unique), `user_id`, `url`, `title`, `body_text` (MEDIUMTEXT on MySQL), `tags`, `archived_at`. FULLTEXT index `ft_page_index` on (`title`, `body_text`) with ngram parser.
