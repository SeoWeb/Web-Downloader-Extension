### Bagaimana Ia Berfungsi

1. Klik ikon sambungan pada mana-mana halaman web yang anda ingin simpan
2. Pilih pilihan anda
3. Klik "Mula Muat Turun"
4. Akses arkib anda dalam folder Muat Turun anda

NOTA! Sesetengah laman web berusaha keras untuk menghalang sesiapa daripada memuat turun kandungan mereka.
