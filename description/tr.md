**Türkçe çeviri yakında eklenecek.**

Web Page Downloader, önemli web içeriğine erişiminizi asla kaybetmemenizi sağlar. Herhangi bir web sitesinin tam, piksel mükemmel kopyalarını çevrimdışı görüntüleme için kaydedin—internet gerekmez.

---

### Ana Özellikler

- **Tam Web Sitesi Arşivleme** - HTML, resimler, CSS, JavaScript ve belgeleri kaydedin
- **Ayrıntılı İndirme Kontrolü** - Esnek filtre sistemiyle tam olarak ne kaydetmek istediğinizi seçin
- **Kurumsal Düzey Performans** - Akış indirmeleri, artımlı montaj ve akıllı yeniden deneme mantığı
- **Güvenilir Gizlilik ve Güvenlik** - %100 yerel işleme, kullanıcı takibi yok
- **Gerçekten Küresel** - 45 dilde tam yerelleştirme

### Mükemmel Kullanım Alanları

- Araştırmacılar ve Öğrenciler
- Gezginler ve Dijital Göçebeler
- Web Geliştiricileri ve Tasarımcılar
- Gazeteciler ve İçerik Oluşturucular
- Dijital Arşivciler

### Nasıl Çalışır

1. Kaydetmek istediğiniz herhangi bir web sayfasında uzantı simgesine tıklayın
2. Seçeneklerinizi seçin - Ne indireceğinizi seçin
3. "İndirmeyi Başlat"a tıklayın - İlerlemeyi gerçek zamanlı izleyin
4. Arşivinize erişin - ZIP dosyasını veya tek HTML dosyasını İndirilenler klasörünüzde bulun

NOT! Bazı web siteleri, içeriklerinin indirilmesini önlemek için büyük çaba gösterir ve bu nedenle bazı web siteleri için indirilen HTML, orijinal HTML'den farklı olabilir.
