**重要網頁內容永不失聯。** Web Page Downloader讓您儲存任何網站的完整、像素級完美副本以供離線檢視——無需網際網路。

無論網站當機、變更,還是您只是需要離線存取,此擴充功能都能確保您始終擁有永久封存檔。

---

### 主要功能

#### **完整網站封存**
儲存使網頁正常運作的所有內容:
- **HTML內容** - 頁面結構和文字
- **圖像** - 所有照片、圖形和背景圖像
- **樣式表(CSS)** - 保留精確的視覺設計
- **指令碼(JavaScript)** - 保持互動元素功能正常
- **文件** - 自動擷取PDF、DOC和其他嵌入檔案

#### **精細下載控制**
使用我們靈活的篩選系統精確選擇要儲存的內容:
- 僅下載圖片用於相片庫
- 僅儲存文字內容,無雜亂
- 取得CSS/JS資源用於開發參考
- 透過排除大型資源建立輕量級封存檔

#### **企業級效能**
專為處理最嚴苛的封存任務而建置:
- **串流下載** - 處理數GB網站而無記憶體問題
- **增量組裝** - 處理導致其他工具當機的巨大HTML檔案
- **智慧重試邏輯** - 從網路中斷自動恢復
- **佇列管理** - 高效並行下載多個資源

#### **值得信賴的隱私和安全**
- **100%本機處理** - 所有工作都在您的瀏覽器中進行,不向伺服器傳送任何內容
- **無使用者追蹤** - 我們不收集分析、瀏覽歷程或個人資料
- **無外部相依性** - 您的資料永不離開您的裝置

#### **真正全球化**
完全本地化為**45種語言**,包括:
英語、西班牙語、法語、德語、日語、中文、阿拉伯語、俄語、葡萄牙語、義大利語、韓語、印地語以及33+種其他語言。

- **單一HTML檔案匯出** - 非常適合共用或透過電子郵件傳送完整頁面
- **純文字模式** - 提取乾淨、可讀的內容,無格式
- **進度追蹤** - 下載期間的即時狀態更新
- **智慧資源偵測** - 自動尋找並儲存所有頁面相依性
- **可自訂篩選器** - 儲存您的偏好設定以供重複使用

### 使用方法

1. **點選擴充功能圖示** 在您想要儲存的任何網頁上
2. **選擇您的選項** - 選擇要下載的內容(HTML、圖像、CSS等)
3. **點選「開始下載」** - 即時觀看進度
4. **存取您的封存檔** - 在下載資料夾中尋找ZIP檔案或單一HTML檔案

就是這樣!無需複雜設定、無需帳戶、無需訂閱。
